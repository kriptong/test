# Концепт сайта студии массажа «ЛИЦА»

Одностраничный адаптивный сайт-концепт на HTML, CSS и JavaScript. Визуальное направление приведено к исходному бренду: используется оригинальный круглый логотип «ЛИЦА» с сайта и его пудрово-розовая / тёмно-коричневая палитра. В проекте реализованы выбор города, фильтры услуг, мобильная навигация и диалог записи с контактами выбранного филиала.

## Запуск локально

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Откройте `http://localhost:4173`.
